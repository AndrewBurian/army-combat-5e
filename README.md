# army-combat-5e

A Foundry VTT module adding a new type of **Group** actor for army-scale combat in D&D 5e.

The goal is to let a GM assemble many creatures into a single army-scale entity and
resolve battles between them, while still letting individual PCs meaningfully
intervene — the pretense laid out in Wizards of the Coast's Unearthed Arcana mass
combat playtests.

## Status

Early. Nothing implemented yet — currently gathering design reference.
